# BlockVerse — Mini-jogo

Um mini-jogo 2D inspirado em jogos de plataformas com personagens, moedas, níveis e exploração em blocos.

## Como jogar
- **A/D ou setas:** andar
- **Espaço/W/seta para cima:** pular
- Encoste nas moedas para coletá-las.
- A cada 5 moedas, o nível aumenta.

Abra **index.html** no navegador para jogar.

> Projeto original criado como uma homenagem ao estilo de jogos de criação e exploração. Não usa código ou assets do Roblox.
